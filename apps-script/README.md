# 將測驗結果寫入 Google 試算表

1. 建立一個新的 Google 試算表（Google Sheet）。
2. 點選選單「擴充功能 > Apps Script」。
3. 刪除預設內容，將本資料夾的 `Code.gs` 全部貼上並儲存。
4. 點選「部署 > 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按下「部署」並授權。
5. 複製產生的網頁應用程式網址（`https://script.google.com/macros/s/.../exec`）。
6. 貼到 `src/lib/config.js` 的 `SHEET_URL`，commit 並 push 到 `main`，GitHub Actions 會自動重新部署網站。

第一筆資料寫入時會自動建立標題列：時間、姓名、年級、Q1–Q10（A/B/C/D）、領導人分數、經理人分數、領導人比例、五個維度的領導人/經理人分數、結果類型、結果名稱。

> 若之後修改 `Code.gs`，需在「管理部署作業」中編輯並選擇「新版本」，網址才會更新為新程式碼。
